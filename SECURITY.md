# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ThoxWarRoom, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email security details to: security@thox.ai
3. Include a clear description of the vulnerability and steps to reproduce.
4. You will receive a response within 48 hours.

## Security Measures

- **Zero-trust architecture**: All connections require authentication
- **Platform secure storage**: Credentials stored in Keychain (iOS) / Keystore (Android)
- **No third-party analytics**: No tracking SDKs, no advertising frameworks
- **Local-first data**: Chats and notes stored on-device, not relayed through developer backends
- **Encrypted transport**: All API calls use HTTPS/TLS

## Scope

This security policy covers the ThoxWarRoom mobile application only. For THOX.ai infrastructure security (ThoxRoute, MeshStack, fleet), contact security@thox.ai directly.
